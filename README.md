# ISKPU-Win
The long awaited (by nobody) Windows port of ISKPU!

## How to use ISKPU?
Just download the executable and the `.pck` file, open it, customize your popup and hit `Execute`!
>You can also toggle "Close Window After Execution" to, well... I think that is self explanatory...
